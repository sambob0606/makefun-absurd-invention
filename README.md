A Python program that writes one original sentence pitching a ridiculous invention for [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) on make.fun.

The pitch:

> A fridge that refuses to open until you confess out loud what you came for, so your midnight snack has to justify itself first.

## Run it

```sh
python3 main.py
```

It writes the pitch (127 characters, one sentence) to `/output/entry.txt`.

The program validates its own output before writing: 1–220 characters, valid UTF-8, exactly one sentence. Standard library only, no network, no input files.
